# Про100Код

Учебный сайт для подготовки к ЕГЭ по информатике на компьютере. Исходный первый экран с анимированными орбитами сохранён; ниже отображается личный план занятий.

## Возможности

- 72 авторских упражнения, поиск, фильтры по теме, сложности и статусу, избранное.
- Две подсказки перед разбором, отдельный учёт самостоятельных решений.
- Настраиваемые тренировки, автосохранение ответов и кода, восстановление таймера.
- Работа над ошибками, история попыток, статистика первых ответов, динамика за неделю.
- Черновик Python с подсветкой, input(), запуском в отдельном Web Worker и остановкой.
- Синхронизация прогресса между компьютерами через текущую учётную запись сайта.
- Светлая и тёмная темы, отключение анимации.

Учебные задания не являются полным вариантом или официальным банком ФИПИ. Номер ЕГЭ обозначает тематическую связь упражнения.

## Разработка

Требуется Node.js 24 и npm. Для браузерной проверки используется установленный Microsoft Edge.

    npm ci
    npm run dev

Открыть http://127.0.0.1:5173/. Локальная база создаётся в .local/preview.sqlite; она не попадает в Git или публикацию. Локальный сервер привязан только к 127.0.0.1 и использует отдельного пользователя для просмотра.

    npm test
    node tests/browser-check.mjs
    npm run build

Браузерные проверки изолируют тестовые данные в памяти. Снимки экранов сохраняются в qa/, не затрагивая учебный прогресс локального просмотра.

## Исходники и размещение

public/ содержит интерфейс и учебные материалы. server/worker.mjs обслуживает API и проверяет идентичность пользователя, которую передаёт Sites. scripts/build.mjs создаёт самодостаточный Cloudflare Worker в dist/server/index.js, статические файлы и метаданные миграций.

.openai/hosting.json сохраняет существующий идентификатор сайта и логическую привязку D1 DB. Таблица learner_state изолирует прогресс по идентификатору пользователя. Изменение схемы: отредактировать db/schema.ts, выполнить npm run db:generate, проверить новую миграцию и опубликовать новую сборку. Применённые миграции не изменять.

Запись прогресса использует ревизии, чтобы обнаруживать конфликты. Клиент объединяет события попыток по устойчивым идентификаторам, избранное и черновики — по времени изменения. При отсутствии связи остаётся локальная копия, изменения отправляются после восстановления подключения. Старый прогресс orbita-progress-v1 переносится без выдумывания отсутствующей истории попыток.

Python работает в браузере через Pyodide 0.28.3. Среда загружается с jsDelivr при первом запуске; выполнение ограничено 10 секундами, вывод — 30 000 символами. Код не исполняется на сервере сайта.
